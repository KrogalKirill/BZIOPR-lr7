# Лабораторная работа №7: Методы распознавания

## 1. Постановка задачи
Целью работы является изучение и программная реализация методов и алгоритмов распознавания образов, применяемых в экспертных системах:
1. Создание обучающего множества (не менее 10 объектов, 2 класса) и признакового пространства (не менее 5 числовых признаков).
2. Реализация алгоритма построения решающих функций на основе **минимального расстояния** к эталонным объектам-прототипам.
3. Реализация алгоритма построения разделяющей гиперплоскости на основе **алгоритма восприятия** (перцептронного обучения с последовательной коррекцией весовых коэффициентов).
4. Проведение обучения моделей, распознавание тестовых контрольных и произвольных пользовательских объектов.
5. Реализация графического интерфейса с протоколированием вычислений и геометрической 2D-интерпретацией.
6. Оценка вычислительной сложности обоих алгоритмов.

Для задачи выбрана предметная область технической диагностики серверных узлов:
- **Класс 1**: Нормальный режим работы.
- **Класс 2**: Предаварийный режим повышенной нагрузки.
Объекты характеризуются 5 признаками: загрузка CPU ($X_1$), использование RAM ($X_2$), температура ($X_3$), ошибки сети ($X_4$) и дисковая задержка ($X_5$).

## 2. Краткое описание решения задачи

### Метод минимального расстояния
1. Признаки нормируются делением на максимальное значение по каждому признаку в диапазоне $[0; 1]$.
2. Для каждого из классов строится вектор-прототип как центр масс (среднее арифметическое объектов класса):
   $$P_{ik} = \frac{1}{\vert{}C_i\vert{}} \sum_{X \in C_i} X_k$$
3. Для каждого класса формируется решающая функция:
   $$D_i(X) = 2(X_1 P_{i1} + \dots + X_N P_{iN}) - (P_{i1}^2 + \dots + P_{iN}^2)$$
4. Объект относится к классу, для которого значение $D_i(X)$ максимально.

### Алгоритм восприятия
1. Инициализируются веса решающей функции $W_0 = W_1 = \dots = W_N = 0$.
2. Вычисляется $D_{12}(X) = \sum_{j=1}^N W_j X_j + W_0$.
3. Если объект Класса 1 распознан неверно ($D_{12} \le 0$), выполняется коррекция на увеличение:
   $$W_j = W_j + X_j, \quad W_0 = W_0 + 1$$
4. Если объект Класса 2 распознан неверно ($D_{12} \ge 0$), выполняется коррекция на уменьшение:
   $$W_j = W_j - X_j, \quad W_0 = W_0 - 1$$
5. Обучение завершается, когда все объекты обучающей выборки распознаются без ошибок подряд ($E = N$). Распознавание осуществляется по знаку: $D_{12} > 0 \implies \text{Класс 1}$, $D_{12} < 0 \implies \text{Класс 2}$.

## 4. Оценка вычислительной сложности алгоритмов

Обозначения:
- $N$ — число объектов в обучающем множестве ($N = 12$);
- $M$ — число признаков ($M = 5$);
- $C$ — число классов ($C = 2$);
- $K$ — число шагов (итераций коррекции) алгоритма восприятия до достижения линейной разделимости.

### 1. Метод минимального расстояния
* **Обучение (вычисление прототипов)**:
  Суммирование координат всех объектов требует $O(N \cdot M)$ операций[cite: 35]. Вычисление квадратов прототипов: $O(C \cdot M)$.
  Итоговая сложность обучения: $O(N \cdot M)$[cite: 35].
* **Распознавание одного объекта**:
  Вычисление скалярных произведений для $C$ классов требует $O(C \cdot M)$ операций[cite: 33]. При $C=2$ — $O(M)$[cite: 33].

### 2. Алгоритм восприятия
* **Обучение**:
  На каждом шаге вычисляется линейная комбинация $M$ признаков ($O(M)$) и, в случае ошибки, выполняется обновление вектора весов ($O(M)$)[cite: 37]. При линейно разделимой выборке за $K$ шагов суммарная сложность обучения составляет $O(K \cdot M)$[cite: 37, 39].
* **Распознавание одного объекта**:
  Вычисление значения скалярного произведения $\sum W_j X_j + W_0$ занимает $O(M)$ операций[cite: 37].
